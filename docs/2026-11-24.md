# Mission · 묶음 안의 자료 처리하기 (Network-007)

## 한 일
- agent_core/assignment_07_f1.py: 중첩 for로 묶음 안의 값 출력
- agent_core/assignment_07_f2.py: 묶음별 합계 출력

## 확인한 결과
- F1 예상: 2, 1, 3, 0 / 실제: 2, 1, 3, 0 (일치)
- F2 예상: 3, 3 / 실제: 3, 3 (일치)

## 새로 알게 된 점
- 바깥 for는 묶음을, 안쪽 for는 그 묶음 안의 값을 꺼낸다.
- 안쪽 반복이 다 끝나야 바깥 반복이 다음 묶음으로 넘어간다.
- F2는 각 묶음 안의 값을 더해 묶음별 합계를 출력한다.
- total = 0을 바깥 반복 안에 두어야 묶음마다 합계가 0에서 다시 시작된다.
  맨 위에 두면 앞 묶음의 합이 남아 3, 6처럼 누적된다.
- 묶음 안의 숫자 순서를 바꾸면 F1 출력 순서는 바뀌지만 F2 합계는 같다.
- total = 0을 아예 없애면 NameError가 난다. ...

## Network-008 · 구조 있는 자료 읽고 저장하기

### F1 · 이름으로 값 찾기
- 한 일: 딕셔너리 log에서 키 "user", "count"로 값을 꺼내 출력
- 예상: kim01 4 / 실제: kim01 4 (일치)
- 알게 된 점: log는 상자(변수 이름)이고, 대괄호 ["user"]가 그 칸을 꺼내는 동작이다.
  이름표(키)는 출력되지 않고 안에 든 값만 나온다.

### F2 · JSON 저장과 복원
- 한 일: 로그 5건을 json.dump로 logs.json에 저장하고 json.load로 다시 읽어 back[0]["user"] 출력
- 예상: kim01 / 실제: kim01 (일치)
- 확인: agent_core 폴더에 logs.json이 생겼고, 열어 보니 큰따옴표로 된 JSON 글자였다.
- 알게 된 점: 변수는 프로그램이 끝나면 사라지지만 파일은 남는다.
  파일은 파이썬 파일 위치가 아니라 터미널의 현재 폴더(pwd)에 생긴다.
