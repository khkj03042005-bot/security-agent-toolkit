## Network-010 기존 처리를 함수로 나누기

### 한 일
- collect_high(values): 3 이상 값만 모아 return (F1)
- summarize(values): "합계 N" 문장을 return → report.txt에 저장 (F2)

### 확인한 결과
- F1: [4, 5] / []
- F2: 화면과 report.txt 모두 "합계 5"

### 새로 알게 된 점
- return을 for 안에 넣으면 첫 반복에서 함수가 끝난다
- print만 하는 함수는 None을 돌려줘서 파일에 쓸 수 없다
- 기본값 매개변수는 뒤쪽에 둬야 한다
