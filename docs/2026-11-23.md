# 여러 값을 하나씩 처리하기 (Network-003)

## 확인한 결과
- F1: kim01, lee02, park03이 한 줄씩 출력됨
- F2: 1, 2, 3이 출력되고 4는 출력되지 않음

## 4가 출력되지 않는 이유
range(1, 4)의 범위는 1 이상 4 미만이기 때문에 4는 포함되어 있지 않다.
4까지 출력하려면 range(1, 5)로 써야 한다.

## 새로 알게 된 점
- 목록에 계정을 추가해도 반복 코드는 그대로 두면 된다.
- for 반복문은 목록에서 값을 하나씩 꺼내 같은 일을 반복한다.
